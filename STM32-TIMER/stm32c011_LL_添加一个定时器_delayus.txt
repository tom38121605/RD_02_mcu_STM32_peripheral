      void delay_us_tim(uint16_t us) 
      {
          LL_TIM_SetCounter(TIM16, 0);   // 清零计数器
          LL_TIM_EnableCounter(TIM16);   // 启动计数
          while(LL_TIM_GetCounter(TIM16) < us); // 轮询直到计数值达到us
          LL_TIM_DisableCounter(TIM16);  // 停止计数
      }

4. mx里的Counter Period为什么设置的是65535       //因为这里不需用到中断，只看计数值来判断延时

答： 正确结论（精准、不啰嗦）
      ARR 绝对不能随便设
      ARR = 定时器能计数的最大值
      你设 ARR=10，计数器最多数到 10
      延时函数最大就只能支持 delay_us(10)
      传 100 会直接卡死 / 死循环

      为什么要设 65535？
      16 位定时器最大值就是 65535
      设这个值 = 解锁最大延时范围（约 65ms）
      这样你的 delay_us(x) 中，x 最大可填 65535
